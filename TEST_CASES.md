# Test Cases — Bank Cards REST API

Формат тест-кейсов: ручное тестирование через Swagger UI и PostgreSQL (psql).

Файл содержит список ручных тест-кейсов для проверки backend-логики и бизнес-правил API.

---

## Auth

### 1. Успешный логин

- **Ввод:** валидные username/password
- **Ожидается:** 200 OK, JWT токен

### 2. Неверный пароль

- **Ввод:** неверный password
- **Ожидается:** 401 Unauthorized

---

## Cards

### 3. Создание карты

- **Ввод:** валидные данные
- **Ожидается:** 201 Created
- Номер карты маскируется в ответе

### 4. Хранение номера карты

- **Проверить БД:**
  - `encrypted_number` ≠ исходному номеру
  - `last_four` содержит последние 4 цифры

### 5. Получение списка карт

- **USER** → только свои карты
- **ADMIN** → все карты
- **Ожидается:** 200 OK

### 6. Получение карты по id

- **Ввод:** валидный id
- **Ожидается:** 200 OK

---

## Transfers

### 7. Успешный перевод

- Баланс достаточный
- **Ожидается:** 201 Created
- Балансы корректно обновлены

### 8. Недостаточно средств

- **Условие:** amount > balance
- **Ожидается:** 400 Bad Request

### 9. Перевод на ту же карту

- **Условие:** fromCardId == toCardId
- **Ожидается:** 400 Bad Request

### 10. Заблокированная карта

- **Условие:** статус BLOCKED
- **Ожидается:** 403 / 400

---

## Roles

### 11. USER удаляет карту

- **Запрос:** DELETE /api/cards/{id}
- **Ожидается:** 403 Forbidden

### 12. ADMIN удаляет карту

- **Запрос:** DELETE /api/cards/{id}
- **Ожидается:** 204 No Content

---

## Надёжность

### 13. Атомарность перевода

- Искусственно вызвать ошибку
- Проверить, что баланс не изменился
- **Ожидается:** rollback
